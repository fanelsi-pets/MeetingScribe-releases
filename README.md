# MeetingScribe — релизы

Нативное macOS-приложение для локальной транскрибации Zoom-встреч (Apple Silicon, macOS 26+).

- **Скачать**: последний DMG — в разделе [Releases](../../releases/latest). Откройте образ и перетащите MeetingScribe в Applications.
- **Обновления**: установленное приложение проверяет ленту `appcast.xml` из этого репозитория (Sparkle) и предлагает обновиться само; сборки подписаны Developer ID.
- Исходный код разрабатывается в отдельном репозитории.
